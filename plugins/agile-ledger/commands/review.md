---
description: Submit a story for verification (In Progress → In Review, no PR yet)
argument-hint: <US-ID | BUG-ID>
---
Using the **Agile-Ledger** skill, move `$ARGUMENTS` In Progress → **In Review**. The work is code-complete on its branch with **no PR yet**. Generate a verification checklist: the acceptance criteria rendered as Given / When / Then test cases plus the Definition of Done. This is the "is it really done?" gate before a PR is opened.

Works for a **bug** too: verify the steps to reproduce now pass and the expected outcome is restored (instead of acceptance criteria).
