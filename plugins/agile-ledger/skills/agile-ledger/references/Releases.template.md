# Releases & Increment

> How we version: **Major.Minor**. A new capability (typically a new epic) ⇒ **Major** (1.0 → 2.0).
> An increment to existing functionality (typically an epic increment) ⇒ **Minor** (2.0 → 2.1).
>
> The 🚧 Increment is Done work awaiting a release decision. `/done-us` adds lines here; `/release`
> cuts a numbered version from them. `/changelog` derives user-facing notes from the history below.
