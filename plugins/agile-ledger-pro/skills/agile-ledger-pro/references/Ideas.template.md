# Ideas — capture inbox

> Raw idea captures from `/idea`, newest first, in any language. This file is a lightweight queue:
> `/triage` reviews each idea, promotes it into `Epic-Backlog.md` (as an epic or a story under an epic),
> and moves the line down to **Triaged** with where it went. Keeping ideas separate keeps the epic
> backlog clean, and keeping the triaged ones is what makes "ideas per month" and the idea → story
> funnel answerable later.
>
> Bugs have their own inbox in `Bugs.md` (use `/bug`); this file is for product ideas only.
