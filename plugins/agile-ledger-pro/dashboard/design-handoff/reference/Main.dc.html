Everywhere

Find any ID or title, run any form command. Every item and view has a hash URL. The rail footer always shows sync state, uncommitted files and who you're viewing as.

The brief's seven questions, answered

1 · Home screen

A to-do list — derived, not stored. Every row is a live query over the snapshot and disappears when it's no longer true. Sprint pulse sits beside it.

2 · Entity, role or workflow?

Workflow navigation — capture, shape, run, ship — with a role lens only on Today. Roles change emphasis, never destinations.

3 · The two-state model

One glyph, two words: “In Sprint · In Review”. The ring is the lifecycle; its fill is the board column. Same mark on the board, the backlog and the item.

4 · Quality warnings

Three layers: a flag on the item, a row in Health, a count in the rail. The toast only says “Saved with 2 warnings — view”.

5 · How much graph?

Draw it locally: one hop around an item — epic, depends on, required by, related bugs. No global graph view; past thirty nodes it becomes decoration.

6 · Mobile

Same IA, responsive. Bottom tabs, the board as a column pager, read plus light actions. Planning and releases stay desktop.

7 · Is the Markdown visible?

Yes — moved, not hidden. Every item shows its file and source lines; Files lives under Ledger; the trust line shows what's changed on disk.

Kept, deliberately

State never colour alone · derived numbers · live reload · warnings over blocks · the generated command sheet · epic progress meters.
