---
description: Detail every User Story under an Epic
argument-hint: <EPIC-ID>
---
Using the **Agile-Ledger Pro** skill, run the `/detail-us` process across **all** stories under `$ARGUMENTS`. Detail each to Ready (story sentence, Gherkin acceptance criteria, estimate, layer, dependencies, INVEST, Definition of Ready). Report which stories reached Ready and which still need input from the user.

Each detailed story's full entry goes into **`User-Stories.md`**; its epic index line in `Epic-Backlog.md` flips to **Ready**. Refresh the overview at the top of both files — roll-up counts **and** index tables, adding a row in `User-Stories.md` for each newly detailed story.
