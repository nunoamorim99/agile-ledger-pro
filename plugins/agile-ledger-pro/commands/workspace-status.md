Using the **Agile-Ledger Pro Workspace** skill, render a dashboard from the ledger repo's `Registry.md` plus every repo folder in it: per repo, the current sprint and goal, unreleased (Increment) count, blocked count, open bugs, and last-sync date. Read-only — and it reads **only the ledger repo**, so the code repos need not be checked out.
