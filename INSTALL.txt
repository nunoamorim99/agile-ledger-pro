Agile-Ledger — installing

You are reading this inside the drop-in bundle, so you already have the files you need.

FULL install (skills + slash commands)
  Unzip this bundle into your project's  .claude/  folder, so you end up with:
    .claude/skills/agile-ledger/            (and agile-ledger-workspace/)
    .claude/commands/agile-ledger/*.md
  Use ~/.claude/ instead to install for all your projects.
  Restart Claude Code (or run /reload-plugins). Commands are namespaced: /agile-ledger:idea

SKILL ONLY (no slash commands, driven by natural language)
  Copy just the  skills/agile-ledger/  folder into  .claude/skills/
  (the skill auto-triggers when you ask for backlog/sprint work).

FIRST RUN
  /init-ledger        creates the ledger repository (one folder per code repo, so your
                      code repos stay clean) with Registry.md + Config.md
  /register-repo .    adds the project you are standing in
  /migrate-ledger     moves a pre-2.0 in-repo Agile-Ledger/ folder into the ledger repo

  From inside a code repo the skill walks up to the sibling ledger repo and matches the
  project by its git remote, so there is nothing to configure.

---
Prefer automatic updates? Install via the marketplace instead and you get new versions
without re-downloading:

  /plugin marketplace add nunoamorim99/agile-ledger
  /plugin install agile-ledger@nunoamorim99

Latest bundles: https://github.com/nunoamorim99/agile-ledger/releases/latest
