Agile-Ledger Pro — installing

You are reading this inside the drop-in bundle, so you already have the files you need.

FULL install (skills + slash commands + the dashboard)
  Unzip this bundle into your project's  .claude/  folder, so you end up with:
    .claude/skills/agile-ledger-pro/            (and agile-ledger-pro-workspace/)
    .claude/commands/agile-ledger-pro/*.md
    .claude/dashboard/                          (the local web dashboard)
  Use ~/.claude/ instead to install for all your projects.
  Restart Claude Code (or run /reload-plugins). Commands are namespaced: /agile-ledger-pro:idea

SKILL ONLY (no slash commands, driven by natural language)
  Copy just the  skills/agile-ledger-pro/  folder into  .claude/skills/
  (the skill auto-triggers when you ask for backlog/sprint work).

FIRST RUN
  /init-ledger        creates the ledger. It ASKS where it should live:
                        - inside this project  -> project-x/agile-ledger/, the eight
                          files right there, committed with the code. One repo, one
                          person: nothing else to clone, and nothing else to run.
                        - its own repository   -> one folder per code repo, so a
                          backlog edit never lands on a developer's branch. Right
                          for an org or several projects.
  /register-repo .    adds a project -- only needed for the "own repository" shape
  /migrate-ledger     moves a pre-2.0 in-repo Agile-Ledger/ folder into the ledger repo

  From inside a code repo the skill walks up to the sibling ledger repo and matches the
  project by its git remote, so there is nothing to configure.

  /dashboard          opens the whole ledger as a local web page (http://127.0.0.1:4173/)
                      Needs Python 3.8+ and nothing else. Binds 127.0.0.1 only.
                      On a manual install, run it directly if /dashboard cannot find it:
                        python3 .claude/dashboard/serve.py

  Already using Agile-Ledger 2.0? Pro reads the same ledger. The folder is still
  agile-ledger/ and the root marker is still a Registry.md opening with
  "# Agile-Ledger Registry" — point Pro at it and carry on, nothing to migrate.

  On a PRE-2.0 ledger (an Agile-Ledger/ folder inside a code repo), run
  /migrate-ledger. It moves the folder into the ledger repo and, if the ledger
  predates the eight files -- a Backlog.md rather than Ideas.md +
  Epic-Backlog.md + User-Stories.md + Bugs.md -- converts the layout too.
